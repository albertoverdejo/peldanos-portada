# Portada de Peldaños

La página que se ve en [peldaños.es](https://xn--peldaos-8za.es) mientras se prepara la versión web de
Peldaños. Es una sola página, sin nada que compilar: `index.html`, dos capturas, la letra Nunito
(licencia OFL) y el icono. La publica GitHub Pages desde la rama `main`; `CNAME` dice el dominio.
